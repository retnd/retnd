# The gate's shards (#1455, #1457), in the order their logs are joined.
#
# Format: one shard name per line, lowercase letters, digits and hyphens.
# Blank lines and lines starting with # are skipped; every other line is a
# shard name and nothing else, so `grep -vE '^[[:space:]]*(#|$)'` of this file
# is the exact list. No columns: which host a shard runs on, its memory fence
# and its slot are the runner's business (scripts/release/run-gate-shard.sh).
#
# Who reads it:
#   scripts/ci-local.sh --list-shards prints the names, --shard <name> runs
#     one of them and refuses anything not listed here.
#   scripts/tests/ci-local-gate.test.sh pins --list-shards to this file and
#     runs every shard against its fixtures.
#   The recorder and the verifier read the same list from the tree being
#     recorded or published, so a shard added, dropped or renamed here is a
#     change to a gate file and shows in the gate_tree.
#
# A serial run (no flag) is every shard's steps in ci-local.sh's own order,
# which interleaves them; it is not this order.
